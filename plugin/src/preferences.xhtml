Automatic indexing Have the backend automatically index your libraries on a schedule, using the Zotero API key configured above. Enable automatic indexing of my libraries View indexing status Indexed-status tags Mark attachments that are indexed with a "✅ rag-indexed" tag, which Zotero shows as a small icon before the title. Tags are added as automatic tags, so Zotero's "Delete Automatic Tags in This Library" also removes them; in group libraries they are visible to (and synced for) all members. Keep indexed-status tags up to date Refresh indexed-status tags Indexed Content Admin settings controlling what content gets indexed, independent of how indexing was triggered. Index Snapshots of webpages When off (default), webpage "Snapshot" attachments (Zotero's default title when saving a page snapshot) are excluded from indexing and from the "Fix unavailable" list, for every user.
